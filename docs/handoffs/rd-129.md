# rd-129: GitHub Action (rd-cli-core-split slice 4)

- `action.yml`: composite action. Installs replaydiff, runs `compare` on given MCAPs, writes report.json/md/txt, appends
  report.md to the step summary, uploads the `replaydiff-report` artifact, posts/updates one PR comment (marker
  `<!-- replaydiff-report -->`, via `gh api`, no third-party comment action), exits with the tool's code.
  Outputs: `verdict` (PASS/FAIL/INCONCLUSIVE/ERROR). `inconclusive: pass` only turns an INCONCLUSIVE exit 2 into 0.
- `replaydiff compare --markdown FILE` + `compare.format_markdown`.
- Tests: `validation/tests/test_action.py` runs the action's compare step as a shell script on the synthetic fixture
  (same: exit 0; gain30, offset2cm: exit 1) and checks it matches `replaydiff.cli.main`. No `validation/compare_proto.py`
  exists in this repo; `compare.py` is the former prototype and `test_compare_proto.py` covers it.
- State: tests green offline. The workflow itself has never run on GitHub; the comment step is untested.
